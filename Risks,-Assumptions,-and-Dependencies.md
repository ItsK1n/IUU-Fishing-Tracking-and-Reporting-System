<h1> Risks </h1>

- Data becoming compromised and unable to use as evidence for prosecution.
  * To mitigate this risk implement cybersecurity measures including encryption to protect sensitive data and secure data transmission protocols. 
-  AIS tracking on commercial vessels malfunctions/ becomes ineffective and detection is not responsive.
   * To mitigate this risk, hire specialists to ensure that alerts for AIS tracking are shown. 
- Insufficient collaboration with governmental agencies determining illegal fishing regulations.
  * Allow for open communication channels between governmental agencies and companies, and hire global employees to ensure relations.
- Operational Risk of AIS tracking
  * Create a system to check fishing monitors to notify and ensure that the surveillance is properly suited. 
- Retaliation from illegal operations
  * Create a legal team to ensure the protection and security of the data of employees.

<h1> Assumptions </h1>

 We have identified the following assumptions that our project relies on.

<h2> Business Assumptions </h2>

- The funding is sufficient for the project. Without proper funding, the project cannot succeed. 
- We are able to consult specialists surrounding data engineers and data analysts while constructing a database, in order to ensure proper data security measures.
- Our project will comply with data privacy regulations. This assumes that fishing companies can grant anonymized location data.

<h2> Project Management Assumptions </h2>

- It is possible to complete the development of the releases within specified time frame to allow for proper roadmap prediction.
- Our solution will have enough funding to cover the costs to ensure feasability

<h2> Technological Assumptions </h2>

- Our solution will use existing cybersecurity capacities to keep data confidential and will not leak any information related to tracking. This is so that the project will not manufacture new cybersecurity solutions.
- We will have access to AWS to access web data securely, in order to allow for cloud storage of fishing vessel information.
- There is technology to determine which companies have turned off AIS tracking. This is to ensure that the tracking is feasible and notifies when AIS has been disabled.
- Transfer of existing data into the constructed database system is feasible.

<h2> User Assumptions </h2>

- Users have existing data analysis skills, to create prosecution reports.
- Users have the shared goal of prosecuting illegal fishing.
- Data analyst employees will not leak existing information.
- Commercial fishing companies will consent to their data being tracked. 

<h1> Dependencies </h1>

- Needs specific third-party servers to store system data such as Microsoft SQL
  * Impact: if there is existing database solution storage, this will mitigate cost of storing data. 
- Funding from governmental agencies committed to protecting fishing
  * Impact: The funding is needed to contribute to a project of this magnitude
- Existing illegal fishing database
  * Impact: Determine what was used to implement illegal fishing, and assess what information is reasonable.
- AWS in order to secure database and data usage
  * Impact: Security is a high priority, therefore imperative to have specialists in the field. 
- Tableau to create standardized data visualizations
  * Impact: the standardization reduces the amount of platforms to visualize data.
