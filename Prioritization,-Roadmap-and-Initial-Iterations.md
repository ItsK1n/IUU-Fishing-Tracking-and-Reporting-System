**Rationale:** <br/>
- The Foundation Phase lays out the essential groundwork by establishing the core framework and systems, database architecture, and initial functionalities needed to support Ocean Guardians United primary objectives. It sets the stage for further development and refinement in future phases.
- User Story: As a data engineer, I want to establish a solid database architecture to efficiently store and manage data, laying the groundwork for future system development and expansion.
- The Monitoring Enhancements phase primary goal is to improve the system's monitoring capabilities to effectively track and respond to illegal fishing activities. This involves enhancing the system's ability to detect suspicious vessel behavior, such as AIS signal disabling or changes in movement patterns or speed, and to provide a real-time snapshot (not monitoring) when detected that can be relevant to authorities.
- User Story: As a law enforcement officer, I want to receive near real-time alerts when suspicious vessel behavior, such as AIS signal disabling or abnormal movement patterns, is detected, enabling swift response and intervention.
- The Optimization and Scalability phase focuses its shift on refining the system's performance, efficiency, and scalability. This phase includes optimizing database architecture (Cloud Architecture) to handle large volumes of data more effectively resulting in reduction of cost in data storage/usage. In additional, using the data gathered in the last year of fishing vessels we can develop a seasonal map changing alerting zones and hot zones based off of seasons. And this phase involves streamlining processes and workflows to improve overall efficiency for stakeholders.
- User Story: As a data analyst, I want to optimize and customize data processing workflows to improve the system's performance enabling faster data retrieval and analysis for more timely decision-making.
- The Community Engagement phase focuses on promoting responsible fishing practices and marine conservation, empowering indirect stakeholders with information to combat IUU fishing. This aligns with Ocean Guardians United's mission to track illegal fishing and raise public awareness of marine conservation.

**Approach to prioritization:** <br/>  When determining the rollout of the capabilities and features we:
- Identified  essential infrastructure and architecture crucial for supporting core functionality of tracking and detecting suspicious fishing activity.
- Prioritize features that directly support key stakeholder needs and Ocean Guardians United primary goals.
- Ensure each release has a central theme that builds off of previous releases.
